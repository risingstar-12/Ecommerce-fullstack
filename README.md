# Full-Stack E-Commerce Website

A full-stack eCommerce application built using React and Django REST Framework. Users can browse products, view product details, register and log in, manage a shopping cart, and place orders.

## Live Demo

**Website:** https://ecommerce-fullstack-theta-coral.vercel.app/

**GitHub Repository:** https://github.com/risingstar-12/Ecommerce-fullstack

## Technologies Used

### Frontend
- React
- Vite
- Redux Toolkit
- React Router
- Bootstrap
- JavaScript

### Backend
- Python
- Django
- Django REST Framework

### Database
- PostgreSQL (confirm this matches your deployed configuration)

### Deployment
- Vercel — React frontend
- Render — Django backend

## Features

- Product listing and product details
- Product filtering
- User registration and login
- Shopping cart management
- Quantity and stock validation
- Checkout and order creation
- Automatic stock updates after successful orders
- Responsive user interface

## Running the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/risingstar-12/Ecommerce-fullstack.git
cd Ecommerce-fullstack
```

### 2. Run the backend

Open a terminal:

```bash
cd server
```

Activate your Python virtual environment, install the dependencies from your project's requirements file, configure the required environment variables, and run the Django development server.

### 3. Run the frontend

Open another terminal:

```bash
cd client
npm install
npm run dev
```

Open the local URL printed by Vite in your terminal.
